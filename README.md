# Portafolio profesional | Carlos López

Sitio web personal bilingüe (español/inglés) desarrollado con **HTML, CSS y JavaScript**. Presenta el perfil profesional, habilidades, tres proyectos académicos, trayectoria y vías de contacto.

**Sitio publicado:** https://carlolopez23.github.io/portafolio-profesional/

## Características
- Diseño adaptable a escritorio y móvil.
- Navegación por secciones y menú para pantallas pequeñas.
- Cambio de idioma español/inglés.
- Tarjetas de proyectos con filtros y ventanas de detalle.
- Animación del proceso de desarrollo con datos JSON, control de pausa y soporte de movimiento reducido.
- Formulario que **prepara un correo en la aplicación de correo del visitante**; no envía mensajes desde un servidor.
- Enlaces a GitHub, LinkedIn, WhatsApp y CV PDF.

## Estructura
- `index.html`: estructura y contenido del sitio.
- `styles.css`: estilos y diseño responsivo.
- `script.js`: traducciones e interacciones.
- `assets/`: icono, imagen de marca, CV y datos de animación.
- `proyecto/`: copia del sitio para la carpeta académica del proyecto.
- `tarea1/`, `tarea2/`, `tarea3/`, `quiz/`, `examen/`: materiales anteriores conservados.

## Ejecutar localmente
Desde la carpeta principal del repositorio, ejecutar `python -m http.server 8000` y abrir http://localhost:8000/. Usar un servidor local permite cargar correctamente `assets/animacion-proceso.json`.

## Publicación
En GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**. Tras guardar, esperar a que finalice la publicación y probar el enlace público en una ventana privada.

## Nota sobre proyectos
Los proyectos descritos son académicos. Sus ilustraciones son gráficas diseñadas para este portafolio y no capturas originales de las aplicaciones.
